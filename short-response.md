# Short Response Questions 
1) If you are collaborating with a classmate the first thing each member needs to do is create a branch. It is important that each member needs to create a brnach so that each member can do their own work without messing up main.

2) Developers use branches so that they can work on a project together without messing up the main branch, so that they can experiment freely if theres something new they want to try in their project, so that they can fix a bug if there is, and etc.

3) Git is a distributed version control system that developers use to take a snapshot of what the code looks like at the moment. Github is a cloud based service that allows developers to store,track,manage and control changes to their code. Git and github work together by allowing developers to make repos and changes,create commits, and etc.

4) They have to do `git add .` before `git commit -m "saving work"` because `git add .` will add every modified file into your next commit and `git commit -m "saving work"` adds a label to the packaged code. The correct command sequence is `git add .`, `git commit -m "saving work"`, `git push`.
